# Welcome to Unemployed (lol)
Swipe-based iOS job search app for new grads. Swipe through tailored listings, save the ones you like, and jump straight to the application. Built with SwiftUI and Firebase.

> 🚧 **In progress**

A swipe-based iOS job search app for new grads. Instead of scrolling through endless job boards, swipe right on jobs you like and left on the ones you don't. Listings are tailored to your preferences, and saved jobs take you straight to the application.

## Features
- **Sign-in options:** email/password, Google, and Facebook via Firebase Authentication
- **Guided onboarding:** collects location, job preferences, resume, and notification permissions
- **Swipe feed:** job listings tailored to your preferences
- **Filters:** by location, job type, and salary
- **Saved jobs:** stored in Firebase and linked to easy-apply or company application pages

## Tech Stack
- **SwiftUI** for the UI
- **Firebase Authentication** for sign-in (email, Google, Facebook)
- **Firebase** for saved jobs and user data

## Running Locally
1. Clone the repo and open `Unemployed.xcodeproj` in Xcode.
2. Create a Firebase project and add your own `GoogleService-Info.plist` to the project (it's not included in this repo).
3. Build and run on a simulator or device.
